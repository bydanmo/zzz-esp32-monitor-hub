# 0.5.8 更新与验证记录

2026-11-01。本次从公开版0.4.0迁移至0.5.8，保留 `apps/`、`firmware/`、`tools/` 分类、原创默认素材和只读演示。源代码与可选资源继续分开。

## 实际变化

- 动画库：网页上传MP4、WebM、GIF、MOV、MKV，选择起点与0.5–4秒片段，串行转码、预览、删除和排序，最多8段。设备从运行时目录获取资源，不需为每段重新烧录。
- 自动播放：设置中可固定一段或队列轮播。每次屏保5分钟只重复同一段，下次屏保才推进一项；任何页面无操作5分钟进入，结束恢复原页，触摸可提前退出。预览不改变队列进度；重启从首项开始。
- 缓存与保存：监控阶段自动同步TF，复用CRC匹配文件；保存不要求先预览，保存后留在设置页。暂停的学习计时允许预览和屏保并保持暂停；运行中及完成待确认会阻止屏保。
- 学习计时：开始前1–120分钟设定，开始后大字倒计时，保留暂停／继续／结束。电脑保持真源，不以测试写入正式学习记录。
- Windows采集：使用原生系统接口和可用的NVML，替代周期性PowerShell/WMI采集；不支持的CPU温度仍报告unsupported。
- 显示：双24行内部DMA缓冲、原地RGB565字节转换、直接传输、等待让出CPU；保留整页动效。SPI仍40MHz，CPU仍160MHz；20ms请求周期不等于整屏50FPS。
- 时钟：柔和5×7暖黄绿点阵、斜面排布和保留背景玻璃；玻璃缓存放入PSRAM。公开默认背景仍使用项目原创场景。

## 验证证据与边界

本次公开源码：89项Node测试、类型检查、生产构建、冷启动隔离检查、236项LVGL host检查、C时钟／偏好／动画目录检查、40组逐像素一致画面与452次延迟DMA完成检查通过。独立ESP-IDF5.4.1／LVGL8.4.0构建通过，普通构建关闭启动基准。FFmpeg实际转换原创视频0.5秒、15帧，并生成预览和封面通过。机器可读结果见[验证清单](../validation-v0.5.8.json)。

维护设备同页基准：单缓冲214.901／227.823／209.892ms；双缓冲136.939／134.860／133.447ms；中位214.901→134.860ms，耗时缩短37.25%。两组均使用新直接发送驱动，同场景、同CPU160MHz、同SPI40MHz，从开始绘制计至最后DMA完成；不是旧0.5.7与新版输入到画面延迟的直接对比。串口重报的是同一批三次测量，未重复计数。

维护者关闭简化动效、切换四页后确认“明显更快，颜色和点击正常”。维护设备的CRT局部动画35.2秒采样为30.00–30.01FPS，三个统计窗口零跳帧，时钟更新持续。上述为私有配置与自备媒体的维护设备结果；公开原创素材未重新刷机验收，不承诺任意整屏素材30／50FPS。

待验收：新版CRT闹钟与返回设置的实体观感、新一轮无人操作5+5、断电偏好保持与24小时稳定性。CI成功不扩展这些结论。代码检查未启停在用Hub、重刷设备或写真实学习记录。
