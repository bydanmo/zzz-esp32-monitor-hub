# DM-01 原创终端概念模型

`terminal-concept.glb` 由本项目 `web/src/three/terminal-model.ts` 的程序化母版导出，包含厚机壳、深屏框、实体控制、录像机底座与卡匣。未使用原作提取模型或下载贴图。

屏幕显示区 3:2，对应 480×320。网页的实时 DOM 屏幕、相机和灯光由运行时独立实现，不包含在 GLB 中。可以在网页选择外壳／强调色后重新导出。

约 23,062 三角形、89 节点、13 材质。归档版本为冰蓝强调、拼色机壳。已检查 GLB 头与资源边界，尚未完成 Blender 人工拓扑验收。

模型使用概念设计单位，没有毫米尺寸、公差、PCB 固定点或工程制造验证。请勿直接作为打印／加工外壳图。
