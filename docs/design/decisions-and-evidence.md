# 已确认的决策、参考与当前状态

整理日期：2026-10-24。用于恢复设计上下文，避免每次重新讨论同一问题，也避免把早期候选当作当前完成项。

## 1. 使用优先级

用户最新明确要求 → 用户已确认且未被替代的设计决策 → 当前可运行实现与验收证据 → 本套流程和视觉语法 → 历史研究／候选方案。

新的平台约束可以要求重新适配，但应说明影响；不能以一张新参考图默默推翻既有决策。实现中的参数只是当前落点，用户仍可调整。

## 2. 共同确定的方向

| 决策 | 依据 | 对后续任务的约束 |
| --- | --- | --- |
| 高度贴近原作视觉语法，自己的页面与素材可原创 | 用户前期访谈 | 研究结构、比例、字体和动作；不照搬游戏业务 |
| 功能界面是主要参考 | 用户明确菜单、背包、角色页、绳网、设置 | 页面先满足真实操作，宣传图作为补充语法 |
| 设备就是主视觉，愿意专门制作素材 | 用户明确 | 首页／详情有可识别的设备主体；高密度页可让工具布局优先 |
| 原创 CRT／录像机式桌面终端 | 用户选择 REF-U11／U12 母题 | 厚壳、深屏框、实体控制、真实 3:2 显示区 |
| 操作图形版＋展示精细版共同保留 | 用户明确双表现 | 同母版，轮廓、部件、贴花身份一致 |
| 维护良好的在用品 | 用户明确轻微使用痕迹、整体干净 | 使用痕迹符合接触位置，不默认锈蚀与重污垢 |
| 页面主题与机壳配色可切换 | 用户多次要求 | 不锁死单一黄黑方案；状态含义独立 |
| 音响、鼠标等优先对应真实功能 | 用户明确 | 业务能力确定后再建立器物表达 |
| 器物化深度先同页对照 | 用户明确 | 重大结构选择提供 A/B；不宣称全部页面已统一选定一种程度 |
| 中文功能名为主，少量有依据的设定名 | 用户明确 | 短标签可有型号和英文索引，正文不游戏化 |
| 接近游戏的明确交互与主体联动，可简化 | 用户明确 | 有选中、进退、联动、中断与简化策略 |
| 动态大字背景是重要识别点 | 用户指出旧样例缺失，并认可后续接近的方向 | 背景需作为独立印刷系统设计，不能仅用灰底卡片 |
| 先规格清单，后选生产范围 | 用户明确 | 候选目录不等于全部委托制作 |

## 5. 还可继续决定的事项

- 最终品牌、字标、命名体系，以及 DM-01 是否继续作为长期品牌型号。
- 各页面的器物化程度，不要求一刀切。
- 终端产品级造型精修、双表现精度及 Blender／制造相关制作范围。
- 音响、输入器物、更多场景与原创插画的正式制作优先级。
- UI 音效、声音语言与声音资源；当前没有默认授权或已确认整套规范。
- 现有主题的最终微调、其他平台的预算与独立视觉验收。
- 公共发布时采用哪些参考派生物，哪些改为原创生产资产。

这些是后续选择点，不阻止使用当前稳定语法完成已授权页面。
