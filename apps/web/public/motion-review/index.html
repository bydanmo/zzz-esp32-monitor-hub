ORIGINAL SIGNAL / 01

原创图形，留在桌面。

默认封面、几何信号视频和 CRT 场景由本项目代码生成。它们不包含游戏截图、角色、音乐或原作视频。

终端场景

480×320，4 秒原创示例。时间轴 30 FPS；网页播放不代表任意嵌入式硬件也能达到同样帧率。

自备素材导入

这是本地命令行流程。使用自己的图片和视频执行：

python tools/media/prepare-crt-assets.py background.png video.mp4 --start 0 --duration 4

背景中的显示区域需要按模板匹配固定窗口；转换后重新构建 Web 和固件，使尺寸及 CRC 一致。详细步骤见仓库的 docs/media.md。
