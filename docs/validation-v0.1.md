## 边界

三维运行时延迟加载模块约 552kB，生产构建仍有 chunk 大小提示。模型停稳／离屏时按需停止绘制，但低端手机没有帧率基准。

固件这轮是模板构建验收；新原创默认视频未单独做完整实机 5+5 分钟周期。此前的约 30 FPS 局部播放结果是特定设备与旧素材的测量，不能替代新资源实测。

GitHub Actions 的执行结果在推送后查看，本地通过不代表远端 CI 已经通过。公共源码不依赖历史研究图片、厂商资料包、个人目标和本机配置。
